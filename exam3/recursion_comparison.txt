TSP Backtracking (Linear/Depth-First):
```
tsp_rec(depth=0)  // Choose first city
├── try city 0: tsp_rec(depth=1)  // Commit to city 0
│   ├── try city 1: tsp_rec(depth=2)  // Commit to city 1
│   │   ├── try city 2: tsp_rec(depth=3)  // Commit to city 2
│   │   │   └── BASE CASE: check path 0→1→2→0
│   │   └── backtrack city 2, try city 3: tsp_rec(depth=3)
│   │       └── BASE CASE: check path 0→1→3→0
│   └── backtrack city 1, try city 2: tsp_rec(depth=2)
│       ├── try city 1: tsp_rec(depth=3)
│       │   └── BASE CASE: check path 0→2→1→0
│       └── backtrack city 1, try city 3: tsp_rec(depth=3)
│           └── BASE CASE: check path 0→2→3→0
└── backtrack city 0, try city 1: tsp_rec(depth=1)  // Now try city 1 first
    └── ... (similar subtree for paths starting with city 1)

Each path goes to full depth (n=3) before backtracking!
```

N-Queens Backtracking (Branching):
```
solve(row=0)  // Try queens in each row
├── place queen in col 0: solve(row=1)
│   ├── place queen in col 2: solve(row=2)
│   │   └── place queen in col 4: solve(row=3) → SOLUTION
│   ├── place queen in col 3: solve(row=2) → CONFLICT
│   └── backtrack, try col 4: solve(row=2) → CONFLICT
├── backtrack col 0, try col 1: solve(row=1)
│   ├── place queen in col 3: solve(row=2)
│   │   └── place queen in col 0: solve(row=3) → CONFLICT
│   └── backtrack, try col 4: solve(row=2) → CONFLICT
└── backtrack col 1, try col 2: solve(row=1)
    └── ... (tries different combinations at each level)

Branches out at each level, doesn't go deep on one path!
```
